# RoboLN Live Build Copilot — quick user guide

Open a project, then choose **Build Copilot** in the project navigation. The original Plan, Practice in 3D, Live Build evidence workbench, Digital Twin and Evidence views remain available.

1. **Describe the project.** Save its goal and available hardware in the existing project planner.
2. **Add equipment.** Choose Add equipment, enter the name/category/quantity and record unknown specifications. Add up to six photos at a time. Confirm storage before saving. Associate equipment with a saved BOM component to make the missing-parts checklist useful. Correct / photos edits identification, models, specifications, source references and quantities.
3. **Add technical evidence.** Expand Datasheets & technical sources. Upload a datasheet or text reference, inspect it and search its excerpts. Documents are not automatically sent to Meta on upload.
4. **Save a provisional assembly.** Use Component library / Add part to saved BOM, or open 3D editor. Search categories, add/select/move/rotate parts, use the gizmo or numeric fields, choose an assembly parent, and save the assembly revision. The optional rover example contains generic, unverified geometry.
5. **Create steps.** Generate guided plan creates a saved project template without a provider key. Alternatively allow project context and choose Ask Meta for build plan. That performs a real provider request when configured. Review the actual proposed sequence and choose Use reviewed build plan; a proposal never starts or completes a physical step automatically. Saved proposals can be reopened from conversation history.
6. **Start Build.** The current step shows its objective, English instruction, component references, checks, common mistakes and safety note. Click a referenced component to highlight/focus it in 3D. Previous Step / Next Step save note drafts before moving. Use the step list to revisit a step.
7. **Inspect a snapshot.** Open the Camera view, choose Open Camera and grant permission. Capture Snapshot, Stop camera or Switch camera when multiple devices are available. Upload Photo is the alternative. Review the local preview, explicitly consent to storage and Save step photo. Select the saved photo and separately consent to provider transmission. Choose Check My Work or ask a photo question. Each request is a snapshot inspection; local preview is not continuous AI vision. Save/discard a pending snapshot before changing steps so it cannot be silently assigned to another step.
8. **Review the response.** Actual provider text appears as formatted headings/lists/code with model/provider metadata and source excerpts. It is saved to your account, project and build step. Inspection can reopen Needs Review, never electrical verification or automatic completion. Provider errors keep saved photos/progress available for retry. Load earlier conversations retrieves older private history in pages of 50.
9. **Record your checks.** Add Step observation notes and acknowledge that you performed the listed checks. Mark Step Complete records USER REPORTED progress. If evidence is required, supply a saved step photo or sufficiently detailed independent notes. Record unresolved issues. Waiting for Evidence, Needs More Evidence, Needs Review and Blocked can be set explicitly.
10. **Listen or dictate.** Speak Instruction, Repeat instruction and Stop Speaking use browser English speech synthesis. Choose an English voice if one is available. Dictate question uses optional browser speech recognition, asks for microphone permission and may use your browser's speech service. Review the text and press Ask AI yourself; dictation never auto-sends. Written controls remain usable if audio is unsupported.
11. **Save and return.** Save Progress stores your current step, notes, issues, experience mode, selected component and current saved assembly revision. Resume Build restores the latest database state after login or restart. Save the assembly revision separately before leaving an unfinished 3D edit. Local unsaved photos are not uploaded automatically.
12. **Inspect history.** Evidence shows saved step photos and AI review alongside the original user-observation/audit workflow. Saved project memory lists recent checkpoints; Settings → Download JSON includes your current private build memory, shared inventory metadata and recent conversations. Binary media stays on authenticated project routes.

Guided mode keeps the current instruction central. Engineering mode adds editable steps, linked components, common mistakes, evidence requirements and technical tools. Both modes use the same plan, equipment, assembly and private progress. Plans and inventory are shared with authorized project members; progress, notes, checkpoints and AI conversations are private per account.

Parent movement and rotation apply a rigid transform to descendants using backward-compatible world-space poses. Reparenting preserves world placement. Interactive snap is 0.1 model units / 15 degrees; exact numeric inputs remain available. Undo/redo covers in-memory scene data edits, up to 50 entries, and resets after a successful assembly save/reload. Gizmos are disabled in exploded view and outside Design mode. A saved assembly/reference change reopens affected confirmations for review.

The authoritative measured results are in FINAL_VERIFICATION_REPORT.md. This release's browser interactions, native camera and real spoken audio were not executed in the release environment; follow docs/MANUAL_ACCEPTANCE_TESTS.md on your machine.
