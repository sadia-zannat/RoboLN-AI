# Known limitations — current Copilot release

- Browser suites are implemented, typechecked and collected but were blocked before page creation by Chromium Unix socket permission restrictions in the command runtime. A separate managed browser could open a blank tab but could not connect to the local application (`ERR_CONNECTION_REFUSED`). No browser workflow, screenshot, mobile layout, pointer gizmo, automated accessibility, native webcam or real audio PASS is claimed.
- No personal Meta credentials were supplied. Text/image/plan connector success is tested using explicit HTTP transport fixtures only. Actual account/model eligibility, image capability, latency, quality, quota and provider retention require your own live validation. Production never substitutes the fixture for an unavailable provider.
- Camera preview is local; AI vision happens only on selected submitted snapshots. Continuous automated video inspection, visual odometry and automatic camera-to-model registration are not implemented.
- Voice playback/input depend on the browser and installed English voices. Recognition may use the browser's external speech service. Native recognition/audio was not exercised; text remains available. Full real-time voice conversation is not implemented.
- Geometry and units are procedural/provisional. Hierarchy transforms are rigid world-space updates, not a CAD constraint solver or physical joint model. No dimension, fit, collision, traction, wiring, voltage/current, torque, insulation, continuity or readiness certification is provided.
- Step completion is an explicit user report. A photograph or provider answer cannot grant physical PASS. Hardware control remains HOLD_NO_EXECUTOR; no autonomous physical actuation was added.
- Save the assembly revision before leaving an unfinished editor; Save Progress records the saved assembly revision and build memory. Local unsaved photos are not automatically uploaded or restored after closing a tab. The UI prevents silent photo relinking on a step change and warns about unfinished scene edits.
- Plans/inventory/photos are shared inside an authorized project; personal progress, notes, checkpoints and AI conversations are scoped by account. Current history paging returns 50 messages per page. A checkpoint history is retained, but rollback to a historical checkpoint is not implemented.
- SQLite/local HTTP and a real backend restart were tested. Windows PowerShell, native devices, live PostgreSQL, Docker/Render/cloud deployment, TLS/load/availability commissioning and current dependency vulnerability advisory audits were not performed here.
- A template-generated build plan is explicitly PROJECT_TEMPLATE, not a provider inference. A provider plan is stored only after explicit user review and remains an unverified proposal. Manufacturer-specific wiring or an electrically validated pinout is not generated without independent evidence.
- Database downgrade removes new Copilot records; back up before schema changes. Old account/chat/telemetry/proposal preservation is verified by migration scripts, not a substitute for an operator backup.

- AI component identification is saved as actual provider review feedback. Users correct/apply inventory fields and BOM associations. Automatic verified multi-object photo-to-BOM conversion is not implemented.
